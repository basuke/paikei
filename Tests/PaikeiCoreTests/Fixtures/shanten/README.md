# シャンテン数の正解データセット

あら氏の「麻雀C言語プログラム集」のシャンテン数テストケース。
配布元: https://mahjong.ara.black/etc/shanten/shanten9.htm (problems.zip)

各行は「牌ID×14 + 期待シャンテン数×3」。

- 牌ID: 0〜33（萬 0-8 / 筒 9-17 / 索 18-26 / 字 27-33）。`HandCounts.index(of:)` と同じ
- 期待値の列順: **一般形(4面子1雀頭) / 国士無双 / 七対子**

| ファイル | 内容 |
|---|---|
| p_normal_10000.txt | 無作為な手牌 10000 |
| p_hon_10000.txt    | 混一色寄りの手牌 10000 |
| p_tin_10000.txt    | 清一色寄りの手牌 10000（分解が最も複雑） |
| p_koku_10000.txt   | 么九牌寄りの手牌 10000 |

tomohxx/shanten-test など複数のシャンテン計算実装が正解データとして使用している。
